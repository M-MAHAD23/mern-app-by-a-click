# 🚀 One-Click MERN Stack Setup

**Save time, skip the manual setup, and start coding instantly!**

## 🎯 What is this?

Tired of repeatedly setting up MERN stack projects for testing? **This tool automates everything**! With just **one click**, you get:
✅ A fully structured **MERN project**
✅ A ready-to-run **Express backend**
✅ A **Vite frontend** with React, Vue, or Svelte (your choice!)
✅ Everything installed and configured!

---

## 🔥 Features

- **One-click setup** for a MERN stack project
- **Express backend** pre-configured with CORS, dotenv, and more
- **Frontend setup** with React, Vue, or Svelte via Vite
- **Fully automated installation** (just run the `.exe` file)

---

## 🚀 How to Use

1️⃣ **Download `setup.exe`** (or run `setup.js` with Node.js)
2️⃣ **Run the file** and follow the prompts
3️⃣ **Select a framework** (React, Vue, or Svelte)
4️⃣ **Done!** Your project is set up and ready to go 🎉

---

## ⚡ Quick Commands

After setup, run:

### **Start Backend**

```bash
cd backend && node server.js
```
